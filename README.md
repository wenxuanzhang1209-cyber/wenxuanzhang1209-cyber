## Flagship: JKinco Listen · 筑听

**A live meeting product for any high-context conversation — hardened in construction
supervision, not limited to it.**

The production product records with a phone or **筑听 Z1**, streams a live transcript,
generates structured minutes, exports Word/PDF, and answers questions grounded in the meeting.
The open edition turns the same product direction into a self-hosted stack with LiveKit, local
ASR/LLM, source access, and a verifiable privacy boundary.

### Why it is more than an AI wrapper

- **Useful while the meeting is still happening.** Live captions and structured minutes are
  part of the same flow, not a post-processing add-on.
- **General product, demanding proof.** Management reviews, customer calls, interviews,
  training, and research are first-class uses. Engineering supervision is the stress test
  because an incorrect owner or responsibility changes the meaning of the document.
- **A defensible trust boundary.** The open edition can run without cloud model calls; CI
  scans the working tree and Git history for API keys, cloud-model traces, and production
  infrastructure details.
- **Measured domain quality.** On ten noisy Chinese meeting clips and 36 high-risk terms,
  local ASR alone recognized 31 / 36; domain correction reached 36 / 36. The synthetic clips
  are cleaner than a real room, so that result is an upper bound, not a promise.
- **977 tests** in the open repository, covering API, security, concurrency,
  templates, export, real-time meetings, and failure paths.

### Product case study: from idea to impact

| Stage | Product decision | Public evidence |
|---|---|---|
| **User insight** | Meetings need value during the conversation, not only a summary after it | Live transcript, automatic minutes, and grounded Q&A in one flow |
| **Product design** | Separate the ready-to-use app from the auditable self-hosted edition | iOS / Android / HarmonyOS product and MIT Open Edition |
| **AI engineering** | Keep model quality observable and the data boundary explicit | Evidence-gated classification, measured domain correction, local ASR / LLM, DOCX/PDF |
| **Deployment** | Make the first useful path short for both users and developers | Three-platform download page, Docker Compose, one-command launch |
| **Adoption evidence** | Publish only what can be verified publicly | Live app, Z1 capture surface, v0.2.0 release, 977 tests, reproducible benchmark |

Commercial adoption and revenue figures are not claimed here. The public proof is the shipped
product, open source, tests, benchmark, documentation, and release history.

### Engineering excellence

| Area | What is implemented |
|---|---|
| **Real-time systems** | Self-hosted LiveKit media, streaming captions, reconnects, meeting controls, and browser UX |
| **Applied models** | Local ASR, domain correction, evidence-gated classification, local LLM generation, and grounded Q&A |
| **Evaluation & reliability** | A reproducible domain benchmark, 977 tests, CI checks, failure-path coverage, and release contracts |
| **Security boundaries** | Redacted secret scanning, production/cloud boundary checks, explicit local credentials, and security documentation |
| **AI-native delivery** | Codex, Claude, and modern coding workflows used to move from prototype to tested implementation |

### A focused layer in the enterprise AI stack

DingTalk, Tencent Meeting, and Feishu already own broad collaboration, identity, messaging,
and distribution. The opportunity for JKinco is not to rebuild that suite.

It is to become the trusted capture-and-document layer that can operate inside strict data
boundaries, preserve evidence and accountability, and adapt deeply to a workflow — then
integrate with the platforms already used by the enterprise. Broad suites win reach; focused
products win the hardest last mile.
